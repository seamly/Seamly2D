Inter Font Family

This directory contains the Inter font family files.

Required files:
- Inter-Regular.ttf
- Inter-Bold.ttf  
- Inter-Light.ttf

Download from: https://fonts.google.com/specimen/Inter

License: Open Font License (OFL)

Inter is a variable font family designed for computer screens. It features a tall x-height to aid in readability of mixed-case and lower-case text.
