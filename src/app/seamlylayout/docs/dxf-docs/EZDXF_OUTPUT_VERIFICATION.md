# Inspecting ezdxf Drawing Output

This document explains how to inspect the ezdxf intermediate representation (Drawing object) that is created during SVG to DXF conversion.

## Overview

The `seamly_svg2ezdxf` crate converts SVG documents into a `Drawing` object (ezdxf-like intermediate representation). This Drawing object is stored in memory during conversion, but can be written to the `output/` directory for inspection.

## Writing Drawing to File

### Using the Helper Function

```rust
use seamly_svg2ezdxf::{svg_to_ezdxf, SvgToEzdxfOptions, write_drawing_to_output};
use svg_dom::Document;

// Convert SVG to Drawing
let doc = Document::parse(svg_content)?;
let drawing = svg_to_ezdxf(&doc, &SvgToEzdxfOptions::default())?;

// Write to output directory
let file_path = write_drawing_to_output(&drawing, Some("my_drawing.txt"))?;
println!("Drawing written to: {:?}", file_path);
```

### Using Drawing Methods Directly

```rust
use seamly_svg2ezdxf::Drawing;
use std::path::PathBuf;

let drawing = /* ... your drawing ... */;

// Write to a specific path
let output_path = PathBuf::from("output/my_drawing.txt");
drawing.write_to_file(&output_path)?;
```

## Output File Format

The output file is a human-readable text file with the following structure:

```
// SeamlyLayout ezdxf Drawing Inspection File
// Generated by seamly_svg2ezdxf

DXF Version: R12
Blocks: 2
Modelspace Entities: 1

=== BLOCKS ===
Block 0: 'piece1'
  Entity count: 1
  Entity 0: LINE on layer 'Piece boundary'

Block 1: 'piece2'
  Entity count: 1
  Entity 1: CIRCLE on layer 'Internal lines'

=== MODELSPACE ENTITIES ===
Entity 0: TEXT on layer 'Text/Annotations'
```

## Output Directory

By default, files are written to the `output/` directory in the project root. This directory is created automatically if it doesn't exist.

**Location**: `output/` (relative to workspace root)

## Example Usage in Tests

```rust
#[test]
fn test_inspect_conversion() {
    let svg = r#"<svg><path d="M0 0 L10 10"/></svg>"#;
    let doc = Document::parse(svg)?;
    let drawing = svg_to_ezdxf(&doc, &SvgToEzdxfOptions::default())?;
    
    // Write to output for inspection
    let file_path = write_drawing_to_output(&drawing, Some("test_output.txt"))?;
    
    // Verify file was created
    assert!(file_path.exists());
    
    // Read and verify contents
    let contents = std::fs::read_to_string(&file_path)?;
    assert!(contents.contains("POLYLINE"));
}
```

## Inspecting Real SVG Files

To inspect the conversion of a real SVG file:

```rust
use std::fs;
use seamly_svg2ezdxf::{svg_to_ezdxf, SvgToEzdxfOptions, write_drawing_to_output};
use svg_dom::Document;

// Load SVG file
let svg_content = fs::read_to_string("input/richmond-shirt_v1_v061-02.svg")?;
let doc = Document::parse(&svg_content)?;

// Convert
let options = SvgToEzdxfOptions {
    create_blocks: true,
    invert_y: true,
    svg_height: Some(1000.0),
    ..Default::default()
};
let drawing = svg_to_ezdxf(&doc, &options)?;

// Write for inspection
let file_path = write_drawing_to_output(&drawing, Some("richmond_shirt_ezdxf.txt"))?;
println!("Inspection file: {:?}", file_path);
```

## File Contents

The inspection file contains:

1. **Header**: Comments and metadata
2. **Summary**: DXF version, block count, modelspace entity count
3. **Blocks Section**: 
   - Block name
   - Entity count per block
   - Entity types and layers
4. **Modelspace Entities Section**:
   - Entity types and layers
   - Entity order

## Limitations

The current inspection format is text-based and shows:
- ✅ Entity types (LINE, CIRCLE, TEXT, POLYLINE)
- ✅ Layer assignments
- ✅ Block structure
- ✅ Entity counts

It does NOT show:
- ❌ Coordinate values (to keep file size manageable)
- ❌ Detailed entity properties (radius, angles, etc.)
- ❌ Binary data

For detailed coordinate inspection, use debug logging with `--nocapture` flag in tests.

## Integration with CLI

When implementing the CLI or UI, you can add an option to write inspection files:

```rust
// In CLI or app_core
if options.inspect_output {
    write_drawing_to_output(&drawing, Some("conversion_inspection.txt"))?;
    println!("Inspection file written to output/conversion_inspection.txt");
}
```
