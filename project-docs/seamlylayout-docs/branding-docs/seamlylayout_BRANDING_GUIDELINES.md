# BRANDING GUIDELINES


## Essential Design Guidelines

### 1. **Layout & Spacing**

* Use consistent padding/margins
* Align elements vertically/horizontally
* Group related controls (forms, lists, action buttons)

### 2. **Typography**

* Choose clear fonts (e.g.,  **Inter** ,  **Montserrat** )
* Use 2–3 font sizes max
* Avoid system defaults when possible

### 3. **Color & Contrast**

* Pick a palette with good contrast (tools like ColorZilla or Figma’s contrast checker help)
* Use subtle backgrounds rather than flat gray/white

### 4. **UI Feedback**

* Buttons should have hover/pressed states
* Form fields need focus/invalid feedback

### 5. **Icons**

* Use consistent vector icons (e.g., Feather Icons, FontAwesome)
* Place them with text labels for clarity
