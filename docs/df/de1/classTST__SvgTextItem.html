Detailed Description

TST_SvgTextItem unit tests for the SvgTextItem graphics item.

Verifies the two guarantees the item exists for: SVG exports of the item contain real <text> elements (not glyph-outline paths), and the item is still discovered by the DXF export's QGraphicsSimpleTextItem walk.
