Check whether path data draws nothing: empty, or one moveto with an optional closepath.

An empty QPainterPath still carries an implicit MoveTo(0,0). The item's scene position moves that point, so QSvgGenerator can emit e.g. "M -1121.38,5595.73 Z" instead of "M0,0".
