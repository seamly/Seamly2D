Detailed Description

QML-accessible controller that owns and manages PreferencesWindow.

Lifetime: one PreferencesWindow is created on the first call to openPreferences() and reused on subsequent calls. The pointer is cleared when the dialog is destroyed (e.g. via the OS close button).

QML usage:
PreferencesController {
id: preferencesController
preferencesModel: preferencesModel
onSaved: { /* preferences persisted */ }
onDiscarded: { /* preferences reloaded */ }
}
