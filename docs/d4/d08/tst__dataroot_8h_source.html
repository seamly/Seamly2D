40/**
41 * @brief TST_DataRoot tests VCommonSettings' user-data root — the single settings-backed
42 * root that patterns, measurements, templates, bodyscans, label templates, images,
43 * backups and layouts are all derived from.
44 *
45 * The suite is hermetic, and deliberately so: every case works inside a QTemporaryDir or
46 * on plain strings, and initTestCase() additionally redirects QSettings' IniFormat/
47 * UserScope base AND VCommonSettings' common-settings base at a temporary directory so
48 * the developer's real settings files are never read or written. Both redirections are
49 * undone in cleanupTestCase().
50 *
51 * No test may touch a path under QDir::homePath(). The home directory CANNOT be faked on
52 * Windows — QFileSystemEngine::homePath() asks the OS through GetUserProfileDirectory()
53 * and only falls back to the USERPROFILE/HOME environment variables when that fails — so
54 * a test that created or removed ~/seamly2d would be operating on the real user's data.
55 */
