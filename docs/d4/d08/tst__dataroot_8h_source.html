41/**
42 * @brief TST_DataRoot tests VCommonSettings' user-data root (Task 34) — the single
43 * settings-backed root that patterns, measurements, templates, bodyscans, label
44 * templates, images, backups and layouts are all derived from.
45 *
46 * The suite is hermetic, and deliberately so: every case works inside a QTemporaryDir or
47 * on plain strings, and initTestCase() additionally redirects QSettings' IniFormat/
48 * UserScope base AND VCommonSettings' common-settings base at a temporary directory so
49 * the developer's real settings files are never read or written. Both redirections are
50 * undone in cleanupTestCase().
51 *
52 * No test may touch a path under QDir::homePath(). The home directory CANNOT be faked on
53 * Windows — QFileSystemEngine::homePath() asks the OS through GetUserProfileDirectory()
54 * and only falls back to the USERPROFILE/HOME environment variables when that fails — so
55 * a test that created or removed ~/seamly or ~/seamly2d would be operating on the real
56 * user's data. First-run resolution is therefore tested through
57 * VCommonSettings::chooseFirstRunDataRoot(), which takes both candidate roots as
58 * arguments and can be pointed at throwaway directories.
59 */
