Detailed Description

Interactive graphics item representing a single pattern piece overlay.

Renders a labeled rectangle for one piece, supports drag-to-move and right-click context-menu rotation (90 CW, 90 CCW, 180, reset). Movement is tracked entirely in scene coordinates so that Qt's item transform never creates a feedback loop with the drag delta.
