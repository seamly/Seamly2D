◆ MigrateSeamlySettingsLocation()

QString VAbstractApplication::MigrateSeamlySettingsLocation ( const QString &  appIniFileName,
const QStringList &  legacyAppIniFileNames,
bool *  migrated = nullptr 
)

MigrateSeamlySettingsLocation migrates application settings files from the previous "Seamly2DTeam" folder to the new unified "Seamly" folder with a subdirectory for each app. Enables future applications to share settings and data.

Parameters
appIniFileNamefilename to use for this app's settings in the new location, e.g. "qt6_seamly2d.ini".
legacyAppIniFileNamescandidate filenames to look for inside the legacy organization folder, tried in order (newest format first), e.g. {"qt6_seamly2d.ini", "Seamly2D.ini"}.
migratedoptional out-parameter set to true if a legacy file was copied into the new location; leave null if the caller does not need to know (e.g. test harnesses, which must never show the migration notice dialog).
Returns
absolute path to this app's settings file in the new unified location.

◆ NotifySeamlyDataLocation()

void VAbstractApplication::NotifySeamlyDataLocation ( )

NotifySeamlyDataLocation shows the one-shot fresh-install notice about where Seamly keeps its data and how existing user files were backed up.

The Windows installer seeds the pending flag into qt6_common.ini when it creates that file on a fresh machine. Whichever Seamly application runs first shows the notice, then marks it shown, so the suite shows it once in total. Only call this from a confirmed GUI-mode code path — a modal dialog would hang a headless or automated run.
